# Nick Whittaker Imagery

Nick Whittaker Photography — ocean and water photography based in Auckland, New Zealand. The site will showcase fine-art prints and support collaborations, commissions, and online print sales.

## Technology

- Next.js with the App Router
- React
- TypeScript
- Tailwind CSS
- ESLint

## Local development

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser.

## Checks

```bash
npm run lint
npm run build
```
